# 微信读书墨水屏版 APK 界面分析

来源：`2.1.2.10245900_900.apk`（官方墨水屏版 v2.1.2），用 androguard 解包。
用途：wekindle 独立客户端 UI 重设计的参考规格。不是照抄——是提取设计令牌（尺寸/字号/配色/布局结构）。

## 1. 整体结构

首页三段式：

1. **顶部**：搜索框（圆角、浅灰底、放大镜图标 + 提示文字）
2. **中间**：书架 = 封面网格（同步手机端书架）
3. **底部**：导航（书架 / 发现 / 我的）

阅读页：点屏幕中央调出工具栏；字体设置面板只有「字号、行距」两档滑条——墨水屏版刻意砍掉了丰富排版自定义。

## 2. 书架网格

- 格子项（`book_grid_item`）：`BookCoverView`（封面）在上，书名在下
  - 书名距封面 `bookshelf_item_title_margin_top = 9dp`
  - 书名单行，末尾省略号（`lines=1, ellipsize=end`）
  - 书名左对齐（gravity=start），不是居中
- 封面：`book_cover` = 底背景 + 封面图（centerCrop）+ 1px 描边 `book_cover_border`
- **封面宽高比 ≈ 0.69**（64dp×93dp、80dp×115dp、44dp×64dp 三组尺寸一致）
- 列表项封面 64×93dp，网格封面 80×115dp（手机上）；6 寸墨水屏设备目测 3 列
- 书架标题行：「书架」+ 右侧「导入」「选择」文字按钮

### 对我们 1072×1448@300dpi 的换算

300dpi 下 1dp ≈ 1.875px（官方以 160dpi 为 1dp）。但墨水屏 App 的 dp 在 6 寸屏上的观感
更接近「封面宽 ≈ 屏宽 / 3 - 间距」。建议直接按比例：

- 3 列，列间距 ≈ 屏宽 × 2.5%（≈27px），左右页边距 ≈ 屏宽 × 4%（≈43px）
- 封面宽 = (1072 - 2×43 - 2×27) / 3 ≈ 310px，高 = 310 / 0.69 ≈ 449px
- 封面下书名 1 行，字号 ≥ 40px（300dpi 屏上约等于手机 15sp 的观感）

## 3. 字号体系（sp → 300dpi px ≈ sp × 300/160 ≈ sp × 1.875）

| 用途 | 官方值 | 换算 px |
|---|---|---|
| 书架项书名 | ~15sp | ~28px（建议放大到 36–40px，Kindle 视距更远） |
| 章节名（大） | 16sp | 30px |
| 书名（详情页标题） | 22–23sp | 41–43px |
| 按钮文字 | 14–15sp | 26–28px |
| 正文笔记/想法 | 15sp | 28px |

教训：我们当前书架行文字约 20px 高，是「看不清」的主因之一。墨水屏字号要比 LCD 大 30–50%。

## 4. 配色

纯黑白 + 灰阶，无彩色：

- 文字：纯黑 `#000000`（辅助文字用 `black_5 ≈ #55000000` 这类半透明黑 → 墨水屏上表现为中灰）
- 背景：纯白 `#FFFFFF`
- 分割线/描边：`black_1 (#11000000)` ~ `black_3 (#33000000)` 极浅灰
- 按钮/强调：黑底白字（墨水屏版把主题色统一到黑）

## 5. 字体资产（APK 内置）

- `SourceHanSerifCN-Medium`（思源宋体 Medium，正文）
- `FZLTHProGBK_DB`（方正兰亭黑 Pro GBK，UI）
- `WeReadLS-Regular/Medium/Bold`（微信读书定制兰亭宋）
- `WeChatNumber`（数字专用字体）
- `PlayfairDisplay`（西文标题）

我们已有 KOReader 的 Noto Sans CJK + Source Han Serif，正文字体策略一致：正文宋体、UI 黑体。

## 6. 阅读页排版

- 正文左右边距 ≈ 20dip（`reader_best_catalog_padding_horizontal` 等一组 20dip 值）
- 目录项垂直间距 16dip
- 工具栏图标 28dip
- 设置面板只有两档滑条：字号、行距（墨水屏版极简）

## 7. 对 wekindle 的重设计清单

1. 书架：文字行列表 → **3 列封面网格**（封面从 WeRead CDN 拉取并缓存，sha256 命名）
2. 顶部加**搜索框**（圆角浅灰底 + 提示文字）
3. 全局字号放大 ~1.5×（300dpi 补偿）
4. 严格黑白：黑字白底，辅助信息 50% 灰，描边 1px 浅灰
5. 阅读页：左右边距 ≈ 40px（20dip×1.875），设置面板只暴露字号 + 行距
6. 底部导航（书架/设置）用文字按钮，黑底白字选中态
