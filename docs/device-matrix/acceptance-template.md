## Phase 2：应用外壳

- [ ] KUAL 入口可启动。
- [ ] 连续启动/退出 20 次，无残留进程、休眠锁或不可恢复残影。
- [ ] 正常退出恢复 Kindle 原生界面。
- [ ] 强制终止后恢复 Kindle 原生界面并释放休眠锁。
- [ ] 点击坐标与横竖屏旋转正确。
- [ ] 列表滚动、弹窗、翻页的局部刷新稳定。
- [ ] 手动全刷可清除残影。
- [ ] 休眠/唤醒 10 次后仍可操作。
- [ ] 本地书架可见，测试章节可打开。

## Phase 3：阅读 MVP

- [ ] EPUB 真实书连续阅读至少 3 章。
- [ ] TXT 真实书连续阅读至少 3 章。
- [ ] 目录跳转、上一章、下一章和章末边界正确。
- [ ] 字体、字号、行距、边距改变后位置语义相近。
- [ ] 断网后已缓存内容可读，翻页不发网络请求。
- [ ] 缓存任务可取消、失败后可恢复、空间不足时有明确提示。
- [ ] 退出再启动恢复正确位置。
- [ ] 休眠再唤醒恢复正确页面。
- [ ] 只上报真实前台阅读时长。

## Phase 4：同步、注释与公众号

- [ ] 远端进度拉取和冲突提示正确。
- [ ] 只在位置映射可靠时上传进度。
- [ ] 进度上传后重新拉取的 round-trip 可接受。
- [ ] 中文、多标签、HTML 实体附近的划线/想法不偏移。
- [ ] 公众号列表可加载。
- [ ] 至少一篇含图片文章可完全离线阅读。
- [ ] 公众号 EPUB 合集通过 `epubcheck`。
- [ ] 阅读统计页面与账号数据一致。

- [ ] 翻页网络请求数为 0。
- [ ] 阅读态 RSS 优先不超过 96 MB；超出时记录原因和型号调整值。
