# wekindle Kindle 版 UI/UX 设计 v0.1

目标设备：Kindle PW4（1072×1448 @300dpi，i.MX6SLL 单核 1GHz，490MB RAM）。
参照：微信读书官方墨水屏版（分析见 docs/official-ink-app-analysis.md）。
约束：e-ink 刷新特性（局部刷新快但有残影，全刷慢且闪屏）、CPU/内存孱弱、无 GPU 加速。

## 1. 导航结构

```
书架（封面网格）
 ├─ 点封面          → 阅读页（直接进，不经详情）
 ├─ 长按封面        → 书籍详情（缓存/导出/进度/删除）
 ├─ 搜索框          → 搜索页（键盘）→ 搜索结果 → 详情
 ├─ 阅读统计        → 统计页
 └─ 退出            → 关闭 app，恢复系统界面

阅读页
 ├─ 点左/右 1/3 屏  → 上一页/下一页（不画按钮，纯热区）
 ├─ 点中央          → 呼出/收起工具栏
 │    工具栏：返回 │ 目录 │ 亮度 −/+ │ 排版 │ 进度条
 ├─ 目录            → 目录页 → 跳章
 └─ 排版            → 字号/行距/边距/亮度

任何页面崩溃或点退出 → launch.sh 恢复系统界面（不允许出现回不去的状态）
```

## 2. 刷新策略（e-ink 专项）

| 场景 | 波形 | 说明 |
|---|---|---|
| 阅读翻页 | 局部 DU（快、无闪） | 每 12 页一次全屏反色全刷清残影（已有 WK_AUTO_FULL_REFRESHES，保持） |
| 书架滚动 | 局部 DU | 停止滚动 1s 后如累计滚动 >2 屏，补一次全刷 |
| 页面切换（书架↔阅读↔目录） | 全屏 GC16 全刷 | 大画面变化必须全刷，否则残影明显 |
| 弹窗/工具栏 | 局部 DU | 只刷工具栏区域 |
| 唤醒恢复 | 全屏 GC16 全刷 | resume 后强制全刷（防白屏/花屏） |

- 刷新合并：LVGL 每帧最多触发一次 fbink_refresh，dirty rect 并集（kindle_host.c 已实现）。
- 阅读页渲染后必须等 e-ink 刷新完成再允许下次翻页（防连点造成波形堆积）→ 翻页防抖 300ms。

## 3. 性能预算

| 操作 | 预算 | 手段 |
|---|---|---|
| 书架首屏可交互 | < 3s | 只建首屏格子（虚拟化），封面只预载前 6 行 |
| 封面显示 | 滚动到后 < 1s | 可见优先队列 + 磁盘缓存 + LRU 30 个 |
| 打开一本书到第一页 | < 5s | 按章加载：目录→当前章→渲染，不预载全书 |
| 翻页 | < 0.8s | crengine 已排版章节翻页是纯渲染；跨章预取下一章 |
| 内存上限 | 进程 < 200MB | 封面 LRU、章节渲染缓冲复用、crengine 单文档 |

- LuaJIT 必须 `-joff`（armv7 JIT 段错误已实锤）。
- 网络请求串行化，阅读相关请求优先于封面/预取。

## 4. 页面布局规格（1072×1448）

### 书架
- 页边距 44px，3 列，列间距 27px，封面 310×449（宽高比 0.69）
- 书名一行 32px，封面下间距 8px，行间距 36px
- 顶部：搜索框（高 64，圆角 8，1px 黑边）→ 标题行（书架（N 本）32px 左，阅读统计/退出 按钮右）
- 未下载封面：白底黑边占位 + 书名文字

### 阅读页
- 正文区：1072×1348（上下各留 50px）
- 底部信息条（40px，24px 灰字）：左「书名」中「章节进度」右「时间」——点击中央才显示完整工具栏
- 默认排版：字号 32px / 行距 130% / 左右边距 44px（300dpi 换算官方 17sp）

### 工具栏（点中央呼出）
- 顶部下拉条（高 88px，黑底白字）：← 返回 │ 书名 │ 亮度 − ● + │ Aa 排版 │ ≡ 目录
- 底部进度条：章节滑块 + 「第 x/y 页」

### 书籍详情（长按进入）
- 大封面（左，207×300）+ 标题/作者/评分（右）
- 按钮组：立即阅读（黑底白字主按钮）│ 缓存整本 │ 导出 EPUB │ 云端进度 │ 清除缓存

### 通用
- 全部黑字白底；辅助文字 50% 灰；描边 1px 黑
- 按钮最小高度 56px（触控目标 ≥ 9mm @300dpi）
- 字体：UI 黑体（NotoSansCJK），正文宋体（思源宋体，打包进 share/fonts）

## 5. 生命周期（白屏问题根因）

- 熄屏：powerd  suspend → app 收到 LIPC 事件 → 停止所有网络/下载任务，释放大缓冲（封面 LRU 清空），允许系统休眠
- 唤醒：resume → reinit fb → **强制全屏重绘 + GC16 全刷**（当前 bug：崩溃后无人重绘 = 白屏；修复后即使如此也要有看门狗）
- 崩溃看门狗：launch.sh 检测非零退出 → 已恢复框架（已实现）；增加：连续 3 次崩溃 → 显示错误页而不是循环重启
- 任何时刻按电源键都不能变砖：suspend guard 用完即还（launch.sh trap 已实现）

## 6. 分期实施

- P1（底线）：crengine 崩溃修复、唤醒重绘、翻页热区+工具栏、刷新策略表落地
- P2（体验）：书架虚拟化、阅读页底部信息条、官方同款字体包
- P3（打磨）：滚动惯性关闭（e-ink 不适合）、动画全禁、目录页大字版
